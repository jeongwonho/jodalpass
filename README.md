# 조달패스 (JodalPass)

나라장터가 어려운 기업이 **참여 가능한 공고인지 판단하고, 첫 입찰을 실수 없이 끝낼 수 있도록 돕는 조달 내비게이터**입니다.

> 현재 상태: 제품 발견·검증 단계. 아직 애플리케이션 코드는 없습니다.

## 제품의 첫 번째 약속

공고 링크를 넣으면 다음 질문에 근거와 함께 답합니다.

1. 우리 회사가 참여할 수 있는가?
2. 부족하거나 확인해야 할 조건은 무엇인가?
3. 지금 무엇부터 해야 하는가?
4. 언제까지 무엇을 제출해야 하는가?
5. 최종 제출을 제대로 완료했는가?

첫 제품의 범위는 `공고 탐색 → 참여 판단 → 준비 → 제출 확인`입니다. 낙찰가 예측, 무인 자동투찰, 모든 조달업무 통합은 첫 출시 범위가 아닙니다.

## 핵심 고객

- 나라장터 등록을 완료했거나 등록 중인 기업
- 첫 1~5회 입찰을 준비하는 대표·신규 담당자
- 3~14일 안에 마감되는 실제 공고가 있는 기업
- 물품·일반용역·IT/마케팅 용역부터 우선 검증

## 수익모델 가설

| 단계 | 상품 | 가격(VAT 포함) |
|---|---|---:|
| 유입 | 무료 공고 진단 | 무료 |
| 첫 제출 | 첫 입찰 패스 | 149,000원/공고 |
| 고위험 검수 | 전문가 안심검수 | 총 490,000원/공고 |
| 반복입찰 | Starter | 월 69,000원 / 연 690,000원 |
| 팀 운영 | Pro | 월 149,000원 / 연 1,490,000원 |
| 다부서 운영 | Team | 월 299,000원 / 연 2,990,000원 |
| 낙찰 후 | 조달 운영 OS | 연 4,800,000원 + 온보딩 990,000원 |

첫 입찰 패스를 구매한 고객이 14일 안에 Starter 연간으로 전환하면 149,000원을 전액 차감합니다. 초기에는 낙찰 성공수수료를 받지 않습니다.

## 출시 원칙

이 저장소에서는 ‘화면이 보이는 데모’를 제품 완료로 취급하지 않습니다. 다음 조건을 모두 충족해야 판매 가능한 릴리스입니다.

- 실제 나라장터 공고로 핵심 흐름을 끝까지 완료할 수 있다.
- 모든 자격·마감·서류 판단에 공고 원문 또는 공식 데이터 출처가 있다.
- 확정·추정·직접 확인 필요를 명확히 구분한다.
- 잘못된 참가 가능 판정보다 보수적인 확인 요청을 우선한다.
- 인증·결제·권한·감사로그·오류처리·모니터링·백업·고객지원이 포함된다.
- 모바일과 데스크톱에서 핵심 흐름을 사용할 수 있다.
- 정상 흐름뿐 아니라 정정공고, 첨부파일 누락, API 지연, 분석 실패를 처리한다.
- 자동화할 수 없는 나라장터 최종 제출 단계는 정직하게 안내한다.

세부 기준은 [납품 가능한 제품 개발 기준](docs/DELIVERY_STANDARD.md)에서 관리합니다.

## 수익 전환 로드맵

고객 인터뷰 수가 아니라 실제 공고와 결제가 다음 단계 진입 기준입니다.

1. 유료 컨시어지 검증
2. 공고·자격 데이터 기반 구축
3. 첫 입찰 완주형 유료 베타
4. 반복입찰 연간 구독 전환
5. 낙찰 후 계약·납품·청구 확장

단계별 목표와 중단 기준은 [수익 전환 플레이북](docs/REVENUE_PLAYBOOK.md)에 기록합니다.

## 개발 작업 규칙

모든 개발 작업은 다음 순서로 진행합니다.

1. 고객 상황과 완료해야 할 결과 정의
2. 공식 데이터 출처 및 실패 가능성 확인
3. 화면 단위가 아닌 전체 사용자 흐름 설계
4. 수용 기준과 테스트 케이스 작성
5. 구현
6. 실제 공고 기반 검증
7. 운영·보안·지원 점검
8. 릴리스 게이트 통과

한 번의 프롬프트로 전체 서비스를 생성하거나, 테스트·보안·운영 설계 없이 ‘MVP 완료’로 표시하지 않습니다.

## 현재 저장소 정책

- `main`: 검증된 문서와 릴리스만 유지
- 기능 작업: `codex/<작업명>` 브랜치 사용
- 제품 코드 추가 전 필수 문서: 사용자 흐름, 데이터 계약, 수용 기준, 실패 시나리오
- 공개 저장소에 인증서, 사업자 개인정보, API 키, 실제 고객 서류를 커밋하지 않음

## 라이선스

아직 라이선스를 선택하지 않았습니다. 공개 저장소라고 해서 코드와 문서의 재사용 권한이 자동으로 부여되지는 않습니다.
