# ADR-0001: 모듈형 모놀리스와 비동기 Worker

상태: Accepted  
결정일: 2026-07-27

## 맥락

조달패스는 공고, 문서, 자격판정, 진행관리, 결제처럼 경계가 다른 업무를 갖는다. 동시에 초기 팀과 트래픽은 여러 서비스를 독립 운영할 만큼 크지 않다. 마이크로서비스를 먼저 선택하면 배포·관측·분산 트랜잭션 비용이 고객가치보다 앞선다. 반대로 하나의 무경계 애플리케이션은 업종과 기능이 늘 때 빠르게 얽힌다.

## 결정

- 한 저장소와 한 PostgreSQL을 사용하되 업무를 명시적 모듈로 나눈다.
- 각 모듈은 domain, application, ports, adapters와 public API를 갖는다.
- 다른 모듈의 내부 코드와 테이블에 직접 접근하지 않는다.
- web과 worker를 별도 실행 단위로 배포한다.
- 모듈 간 후속 처리는 공개 명령·조회 또는 계약 이벤트로 연결한다.
- package exports, 금지 import, 순환 의존 테스트로 경계를 자동 검사한다.

## 결과

장점:

- 단일 트랜잭션과 단순한 로컬 개발을 유지한다.
- 마이크로서비스 없이도 업무·데이터 소유권을 명확히 한다.
- 실제 필요가 생겼을 때 모듈을 서비스로 옮길 수 있다.
- 장시간 문서·분석 작업이 웹 요청을 막지 않는다.

비용:

- 경계 규칙을 CI와 코드리뷰로 지속 강제해야 한다.
- 같은 DB를 사용하므로 물리적 격리는 아직 없다.
- 이벤트 전달과 재시도 운영이 필요하다.

## 재검토 조건

독립 확장, 장애 격리, 별도 팀 소유, 보안 격리 중 하나가 실제 지표로 확인될 때 해당 모듈의 서비스 추출을 검토한다.
